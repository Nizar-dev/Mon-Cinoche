# Mon Cinoche
Sample Android App for demostrating the use of MVVM architecture with Jetpack Compose ui, navigation component, retrofit to use TMDB Api and room to 
store locally user's preferences.

https://github.com/user-attachments/assets/9b9f58e2-6f90-424b-8ca3-44f0d1184d46


# Tech Stack
- Jetpack Compose UI
- Material 3
- Jetpack Navigation Component V2.8.5
- Kotlin V2.0.21
- Kotlin Flows
- Kotlin StateFlows
- Coroutines V1.8.1
- JsonSerialization V1.5.1
- Room V2.6.1
- Hilt 2.48
- Gradle
- coilCompose V2.6.0
- ksp 2.0.21
